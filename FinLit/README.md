# Tengely
App for financial literacy.

Пользовательское название приложения — **Tengely**, помощника — **Tengely AI**. Технические имена Xcode-проекта, Bundle ID и Firebase-проекта сохранены для совместимости с существующей установкой и данными.

## Формат выписки

Поддерживается только оригинальная английская PDF-выписка Kaspi Gold. Откройте карту в банковском приложении → «Выписка», выберите период и английский язык (English). Сохраните PDF через «Поделиться» → «Сохранить в Файлы» и загрузите его в «Аналитике». В таблице должны быть колонки Date, Amount, Transaction и Details. Выписки других банков, фото и скриншоты не поддерживаются. Перед разбором операций приложение проверяет реквизиты банка и заголовок документа; упоминание банка в описании перевода не считается подтверждением формата. Это проверка поддерживаемого формата, а не подлинности документа.

## Настройки и оформление

Во вкладке «Настройки» доступны системная, светлая и тёмная темы с предпросмотром. Выбор сохраняется на устройстве и применяется ко всем окнам приложения при запуске и переключении. Системный вариант следует оформлению iPhone.

Профиль пока локальный. Вход через Apple/Google и перенос локальных данных между устройствами не реализованы: в проекте нет Firebase Auth, OAuth Client ID для Google и Sign in with Apple entitlement. Пользовательские данные и идентификаторы текущих битв при смене темы не меняются.

## AI-сортировка выписки

### Проверка спорных операций

В Аналитике кнопка «Проверка» показывает количество операций, ожидающих решения. Этот же экран доступен из AI-чата: «Проверить» → «Спорные операции». Сразу видны нераспознанные платежи и противоречия явным признакам выписки. Кнопка «Проверить с AI» отдельно анализирует остальные операции пакетами до 40 и сохраняет предложения с причинами. Прогресс отражает число полученных результатов; при остановке, потере сети или лимите готовые результаты остаются на устройстве.

Можно принять предложенную категорию, подтвердить текущую или выбрать другую. Суммы и исходные описания эта проверка не меняет. Переключатель «Запомнить» сохраняет правило для того же продавца и банковского типа операции (например, карточные покупки отдельно от переводов). Изменения не применяются массово к остальной истории. Проверенные операции не отправляются повторно, пока их данные не изменились. Персональные решения защищены от позднего ответа AI; сброс выписок удаляет решения по отдельным операциям, сохраняя выученные правила продавцов.

После разбора PDF приложение отправляет операции на локальный/развёрнутый proxy, а proxy вызывает OpenRouter с моделью `nvidia/nemotron-3-ultra-550b-a55b:free`. Если proxy недоступен, остаются локальные категории из `Categorizer.swift`.

1. Создайте ключ на [OpenRouter](https://openrouter.ai/keys).
2. Запустите proxy:

```bash
cd openrouter-proxy
cp .env.example .env
# впишите OPENROUTER_API_KEY в .env
npm start
```

3. В `AI_API_BASE_URL` в `FinLit/Info.plist` уже настроен опубликованный HTTPS proxy для физического iPhone. Для локальной разработки можно указать `http://127.0.0.1:8787` в симуляторе или адрес Mac в локальной сети на iPhone.

Ключ OpenRouter нельзя добавлять в iOS-приложение: любой пользователь сможет извлечь его из бинарника.
